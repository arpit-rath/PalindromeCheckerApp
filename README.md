## Palindrome Checker Approaches using Java

A Java-based application that demonstrates **13 different approaches** to checking whether a string is a palindrome. Each implementation is developed as a separate use case in its own Git branch, showcasing the evolution of the project from basic logic to advanced object-oriented design and performance comparison.

The **main branch** contains the final version (**UC13**) with performance comparison between different palindrome-checking strategies.

### Branch Structure - 

| Branch | Description |
|---------|-------------|
| UC1-WelcomePage | Basic project setup and welcome page |
| UC2-Hardcoded_Palindrome_Result | Simple hardcoded palindrome check |
| UC3-Palindrome_String_Reverse | Palindrome check using string reversal |
| UC4-Palindrome_Character_Array | Character array comparison approach |
| UC5-Palindrome_Stack_Based | Stack-based palindrome checking |
| UC6-Palindrome_Queue_Stack | Queue and Stack combination approach |
| UC7-Palindrome_Deque_Based | Deque-based palindrome checking |
| UC8-Palindrome_Linked_List | Linked List implementation |
| UC9-Palindrome_Recursive | Recursive palindrome checking |
| UC10-Palindrome_Case_Insensitive | Case-insensitive palindrome validation |
| UC11-Palindrome_Object_Oriented | Object-oriented implementation |
| UC12-Palindrome_Strategy_Pattern | Strategy Design Pattern implementation |
| UC13-Performance_Comparison | Performance comparison of all approaches *(Main Branch)* |

### Project Setup Guide - 

 1. Clone the repository: ```bash git clone https://github.com/yourusername/palindrome-checker-app.git```
 2. Navigate to the project: ```bash cd palindrome-checker-app```
 3. Run the application: Compile & run the Java application using your preferred IDE (IntelliJ IDEA, Eclipse, VS Code) or the command line
